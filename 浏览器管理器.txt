## 推荐产品形态

  ### v1
  1. Profile CRUD（独立目录）
  2. 引擎：Chromium + Firefox
  3. 订阅导入 mihomo
  4. 启动时绑定：proxy + timezone + locale + geo
  5. 一键检测页：IP/时区/语言/经纬度
  6. 停止/清理/导出配置

  ### v2

  - 节点国家 → 自动推荐时区/语言/geo 模板
  - 指纹模板（平台、字体、WebGL 基线）
  - 路由规则：仅浏览器进程走代理
  - 会话备份/恢复

  ### v3

  - 反检测引擎矩阵（Camoufox / Patchright）
  - data/app.db（SQLite）：索引、状态、启停、节点绑定、审计
  - data/profiles/<id>/profile.json：该配置真相源
  - 启动前做 DB ↔ 目录 一致性校验
- 开机不必自启，但要支持“恢复上次会话”
  - 禁止写 HOME、禁止改系统代理
  - 临时文件只进 tmp/，定期 GC
  - 订阅导入 / 定时更新 / 失败保留旧表
  - 每 Profile 独立 mixed-port（或独立 socks 入站）
  - 节点收藏、延迟测速、按国家分组
  - 「选节点 → 自动套用 tz/locale/geo 模板」
  - 健康检查：IP 变更后自动重绑环境包
  - 从出口 IP 反推推荐模板
  - 同国城市随机（防千篇一律）时区、语言、Accept-Language、Geo 抖动、分辨率、平台、UA 策略
- 一键导出 profile zip（cookies/storage/扩展/配置）
- 统一扩展目录 runtime/extensions/
  - profile 级启用列表
- 导出禁止脱敏

  ### v4
1.Cookie 导入/导出/注入：支持通用JSON/Base64格式导入导出，能在浏览器启动前提前注入Cookie，实现“秒登录”状态，无需手工输密码。
2.登录态健康巡检：定期（如每天/每周）静默访问目标网站，检测Cookie是否失效，若失效则打上“需重登”标签并通知。
3.环境快照（时间旅行）：对某个Profile创建还原点（包含Cookies、LocalStorage、Session），做高风险操作前拍一张，出问题一键回滚，不用重新配置环境。
4.节点故障自动切换：检测到当前节点不通或IP归属地突变时，自动从同国家候补节点池中切换，并立即重绑环境包，整个过程浏览器不重启（保持页面操作连贯）。
5.节点延迟测速与优选：内置按国家/地区测速排序
6.WebRTC 彻底防漏：除了常规禁用，增加“代理伪装”模式，即便网站强行探测WebRTC，也只显示代理IP而非真实IP。
7.DNS 防泄露：强制指定DoH（加密DNS），避免系统默认DNS解析时暴露网络链路特征。
8.差异备份：导出Profile.zip时，支持“增量导出”（仅导出变化的Cookies和Storage），大幅缩小备份包体积。
9.标签页分组记忆：关闭浏览器时，下次打开自动还原上次的标签页分组（如：账号A打开亚马逊后台+邮箱+ERP）。
10.右键菜单增强：在网页上右键增加“切换当前Profile代理节点”或“将此页迁移至其他Profile”的快捷入口。
