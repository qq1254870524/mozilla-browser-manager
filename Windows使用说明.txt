Mozilla Browser Manager — Windows 使用说明
============================================
版本: 1.10.9-v10.9

【唯一运行目录】
  C:\Users\zhang\Desktop\Mozilla

【禁止】
  - 不要从 \\wsl.localhost\Ubuntu\home\baoge\Mozilla 双击 bat
  - 不要在 System32 下运行
  - 开发只在 Ubuntu: /home/baoge/Mozilla

【四个按钮】
  1. 下载依赖.bat   — 首次或更新依赖
  2. 启动客户端.bat — 桌面客户端（推荐）
  3. 启动WEB.bat    — 浏览器打开管理台 http://127.0.0.1:17888
  4. 停止WEB.bat    — 停止 WEB

【没网时排查】
  1. 任务管理器结束 mihomo.exe / 残留 chrome
  2. 确认订阅是「良心云」，节点已选
  3. 看 logs\mihomo-端口.log 是否有 Mixed proxy listening
  4. 再点一次「启动客户端」后启动环境

【开发同步】
  WSL: cd /home/baoge/Mozilla && bash scripts/export_to_windows.sh
